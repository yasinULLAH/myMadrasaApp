## 🌟 Overview | تعارف

### English
**Madrasa Management System** is a comprehensive, all-in-one digital platform designed specifically for Islamic schools, madrasas, and religious educational institutions. Built by **Bannu Software Solutions**, this system streamlines every aspect of madrasa administration—from student enrollment and fee collection to Quranic memorization (Hifz) tracking and financial reporting.

### اردو
**مدرسہ مینجمنٹ سسٹم** ایک مکمل، آل ان ون ڈیجیٹل پلیٹ فارم ہے جو خاص طور پر اسلامی اسکولوں، مدارس اور مذہبی تعلیمی اداروں کے لیے تیار کیا گیا ہے۔ یہ سسٹم **بنوں سافٹ ویئر سولیوشنز** کی طرف سے تیار کردہ ہے، جو مدرسہ کے انتظام کے ہر پہلو کو آسان بناتا ہے — طالب علم کے داخلے اور فیس وصولی سے لے کر قرآنی حفظ کی پیشرفت ٹریکنگ اور مالی رپورٹنگ تک۔


### 🐛 Troubleshooting | ٹربل شوٹنگ

#### Common Issues | عام مسائل

| Issue | Possible Cause | Solution |
|-------|---------------|----------|
| **App not loading** | Browser cache, network issue | Clear cache, check internet, try incognito mode |
| **Data not saving** | Storage quota exceeded, browser restriction | Clear old data, check browser settings, use Chrome |
| **Login failed** | Wrong credentials, case sensitivity | Verify username/password, check caps lock |
| **Print not working** | Browser print blocker, popup settings | Allow popups, use Ctrl+P, try different browser |
| **Google Drive sync fails** | OAuth expired, network issue | Reconnect account, check internet, verify permissions |
| **APK installation blocked** | Unknown sources disabled | Enable "Install from Unknown Sources" in Android settings |
| **Slow performance** | Large dataset, old device | Clear unused data, use sample data mode, update browser |
